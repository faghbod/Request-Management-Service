# اسکلت سولوشن

سولوشن شامل چهار پروژه Domain، Application، Infrastructure و API است. ساختار پوشه‌ها و زیرساخت تزریق وابستگی، EF Core و Unit of Work برای توسعه پروژه جدید حفظ شده‌اند. نام فعلی پروژه‌ها تا تعیین نام پروژه جدید حفظ شده است.

برای اجرا، .NET SDK 10 را نصب کنید و مقدار `ConnectionStrings:DefaultConnection` را در تنظیمات محلی یا متغیر محیطی تعیین کنید. تنظیمات JWT محیط توسعه در `appsettings.Development.json` قرار دارد؛ در سایر محیط‌ها مقادیر `Jwt:Key`، `Jwt:Issuer` و `Jwt:Audience` را به‌صورت امن تنظیم کنید. کلید باید حداقل ۳۲ بایت باشد. شناسه کاربر جاری از claim عددی `user_id` خوانده می‌شود.

پس از افزودن موجودیت‌ها و پیکربندی‌های پروژه جدید، migration جدید بسازید. migration پروژه قبلی حذف شده است.
